# Wioska AI — prototyp

Pierwszy prototyp symulacji jest projektem Godot 4.

## Uruchomienie

1. Zainstaluj Godot 4.
2. W Godot wybierz **Importuj** i wskaż plik `project.godot` z tego folderu.
3. Uruchom projekt klawiszem F6/F5 lub przyciskiem ▶.

## Sterowanie

- **Spacja** — pauza/wznowienie.
- **1–5** albo kliknięcie mieszkańca — wybór postaci.

## Co już jest w prototypie

- pięciu mieszkańców z różnymi cechami, zawodami, umiejętnościami i prywatnymi rzeczami;
- potrzeby głodu, odpoczynku i ciepła;
- zbieranie jedzenia i drewna do wspólnego magazynu;
- budowanie kolejnych domów;
- ruch mieszkańców i log zdarzeń;
- prosty podgląd ekwipunku wybranej postaci.

Grafika jest na razie zastępcza. Assety zostaną podłączone po wyborze jednej spójnej paczki. AI i automatyczne przygotowanie Ollamy będą osobnym etapem; modelu nie przechowujemy w repozytorium.
