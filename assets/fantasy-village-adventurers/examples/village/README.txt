MOVING VILLAGE SHOWCASE
HappyHustle

Open index.html in a browser with JavaScript and Canvas support.
The demo is self-contained and needs no network connection.
Pause, restart, change speed, scrub the timeline or show character names.
All six characters use the included four-direction idle and walk clips.
The 10.4-second loop has staggered, staged paths and depth-sorted scenery.
This is a visual example without collision, navigation or player controls.
Artwork and character motion made with PixelLab. See ../../LICENSE.txt.
